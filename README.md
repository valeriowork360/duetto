# Duetto

Due video YouTube insieme sul telefono, ognuno con il suo volume.

Sito: https://valeriowork360.github.io/duetto/

- `index.html` – l'app
- `config.json` – libreria consigliata (esercizi fissi, playlist, canali)
- `videos.json` – generato automaticamente ogni 8 ore da `.github/workflows/aggiorna-video.yml`
- `cloudflare-worker.js` – ponte per "I tuoi canali"
- `ISTRUZIONI.md` – guida
